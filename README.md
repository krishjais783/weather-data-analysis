# Weather Data Analysis & Visualization

## 🔧 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Project Overview
This project analyzes weather data by cleaning the dataset, handling duplicates, and performing statistical analysis.

## 📈 Analysis Performed
- Temperature (mean, max, min)
- Wind speed analysis
- Correlation between variables

## 📉 Visualizations
- Temperature distribution
- Temperature vs radiation
- Heatmap
- Wind speed distribution

## 🔍 Key Insights
- Temperature is mostly in a moderate range
- Solar radiation shows a positive relationship with temperature
- Wind speed has minimal impact on temperature
